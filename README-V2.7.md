# Lao Web Studio V2.7 — Admin Workflow

## New workflow features
- Customer detail page (`admin-customer-detail.html`)
- Seven-step customer workflow
- Priority, owner, follow-up date, deadline and project name
- Customer activity history
- Fast call, WhatsApp and email actions
- Customer search plus priority and follow-up filters
- Dashboard tasks for overdue follow-ups and high-priority customers
- Existing V2.6 pages, Supabase connection and data remain unchanged

## Supabase update
Run `supabase-migration-v2.7.sql` once in Supabase SQL Editor after the V2.4 and V2.5 migrations.
Do not rerun the full setup and do not create a new Supabase project.
